In one sentence

Google Calendar data is used only inside the owner’s Home Assistant instance to display event colors.

1. Scope

This policy describes Calendar Colors for Home Assistant, a private, owner-operated integration that connects a Home Assistant installation to Google Calendar. The public informational site does not provide accounts or process calendar data.

2. Google data accessed

The integration requests the calendar.readonly OAuth scope. Google may return calendars the authorizing account can read, calendar metadata, event records, recurrence and time identifiers, event color identifiers, custom label identifiers and colors, and synchronization tokens.

The integration does not request permission to create, modify, share, or delete calendars or events.

3. How Google data is used

Google data is used solely to match Google Calendar events with events already displayed by Home Assistant and to resolve the correct event color. The browser companion receives only limited identity, timing, recurrence, color, and color-source metadata needed for that match. It does not receive event titles, descriptions, locations, attendees, email addresses, label names, or the Google calendar identifier through the companion color API.

Google user data is not used for advertising, profiling, eligibility decisions, or training machine-learning models.

4. Storage and retention

OAuth tokens and configuration are stored by the owner’s Home Assistant installation. Event responses and synchronization state are cached temporarily in that installation’s memory to reduce Google API requests and are discarded when Home Assistant restarts. The integration does not operate an external database or developer-controlled application server.

5. Sharing and disclosure

The integration communicates directly between the owner’s Home Assistant installation and Google’s APIs. It does not transmit Google Calendar data to the application developer, sell it, or share it with advertisers or data brokers.

Within Home Assistant, limited color metadata is available only to authenticated users who already have permission to read the configured calendar entity.

6. Security

The integration uses Home Assistant’s OAuth storage and authenticated WebSocket permissions. Tokens are not written to application logs or committed to the public source repository. No security method can guarantee absolute protection, so the Home Assistant owner remains responsible for securing their installation and Google Cloud credentials.

7. Your control

Access can be stopped at any time by removing the Calendar Colors integration in Home Assistant, deleting its application credentials, or revoking the application from the Google Account’s third-party access settings. Removing the integration deletes its Home Assistant configuration and ends future Google API access.

8. Website data

This informational website uses no accounts, analytics, advertising, tracking pixels, local storage, or cookies. Standard infrastructure logs may be processed temporarily by the hosting provider for security and reliable delivery.

9. Children

The integration is a private home-automation utility and is not directed to children or offered as a public consumer service.

10. Changes and contact

Material changes will be reflected on this page with a revised effective date. Privacy questions may be sent to the developer contact address displayed on the Google OAuth consent screen.
