Calendar Colors is a read-only companion for Home Assistant. It retrieves Google Calendar color metadata and applies the exact event colors inside a locally operated dashboard.

How it works

A short, direct data path

Authorization connects Google directly to the Home Assistant instance that requested access.

  1. G
    Google CalendarReturns authorized calendar and color metadata
  2. → H
    Home AssistantMatches event identity and resolves its display color
  3. → ▦
    Local dashboardReceives only the metadata needed to render colors

Data use

Narrow access for one purpose

What is accessed

Readable calendar metadata and event records required to associate Google’s event and label colors with existing Home Assistant calendar events.

Why it is accessed

Only to reproduce the calendar owner’s chosen event colors on a local Home Assistant dashboard.

Where it is stored

OAuth credentials remain in Home Assistant. Working event data is held temporarily in local memory and is discarded when Home Assistant restarts.

How to revoke access

Remove the integration in Home Assistant or revoke the application from the Google Account’s third-party access settings.
